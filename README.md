# 龙头猎手 · A 股龙头战法决策 Skill

> 六大模块的龙头战法决策助手，所有判断均可被数据与规则复现。

## 六大模块

| 模块 | 能力 | 脚本 |
|------|------|------|
| 一 · 龙头识别 | 龙头概率评分、板块效应、龙虎榜席位 | `dragon_scorer.py` / `concept_heat.py` / `lhb_analyzer.py` |
| 二 · 买点判断 | 打板 / 低吸 / 竞价的入场条件 | — |
| 三 · 持有与卖出 | 分歧、见顶、格局的退出规则 | — |
| 四 · 仓位计算 | 按龙头概率映射建议仓位 | — |
| 五 · 复盘记录 | 决策链路落地为标准复盘记录 | — |
| 六 · 市场环境 | 全市场最高连板、情绪档位 | `market_env.py` |

## 设计要点

- **量化优先**：每个判断必须附具体数字与阈值，禁止「走势较强」这类无锚表述。
- **概率而非确定性**：输出为概率区间（如「成为龙头的概率约 65%–70%」）。
- **强制前置校验**：涉及买卖建议前必须先跑模块六确认市场情绪档位；
  模块六返回「空仓观望」时，模块二默认给出「不建议入场」，模块三倾向「减仓/清仓」。
- **风险必标注**：每次判断附 1–2 条主要风险点。

## 快速开始

```bash
pip install -r requirements.txt
cp .env.example .env   # 填入 PandaData 凭据

# 1. 先取全市场最高连板
python scripts/market_env.py --date 20250127

# 2. 再做龙头识别（把上一步的 max_streak 传入）
python scripts/dragon_scorer.py --symbol 000001.SZ --theme 国家级 --market-height 5
```
